Agora es un runtime de escritorio nativo para agentes, hecho por [Olimpia](https://olimpia.dev). Un daemon en una máquina Linux corre un display X y un Chromium por workspace, y muchos agentes lo comparten. Cada agente es un **cursor** con su propio token acotado, puesto de input, pestañas, estado y resultado estructurado. Los agentes lo controlan a través de `agora mcp`, un servidor MCP por stdio con 52 herramientas.

## Conectate en tres pasos [#connect-in-three-steps]

<Steps>
  <Step title="Check that Agora is running">
    En la máquina donde corre el agente:

    ```bash
    agora api GET /v1/health
    ```

    Si no tenés `agora`, mirá [instalación](/install).
  </Step>
  <Step title="Add the MCP server">
    ```bash
    claude mcp add agora -e AGORA_TOKEN=<cursor token> -- agora mcp
    ```

    Codex, otros clientes y cómo conseguir un token de cursor: [Conectar](/agents/connect).
  </Step>
  <Step title="Install the skill (optional)">
    ```bash
    bunx skills add olimpiacloud/agora-skills
    ```

    Le enseña al agente los flujos baratos: primero el snapshot, actuar por ref, esperar eventos y pasarle los CAPTCHAs a un humano.
  </Step>
</Steps>

## Qué puede hacer un agente [#what-an-agent-can-do]

| Tarea | Herramientas |
| --- | --- |
| Leer páginas web y actuar sobre ellas | `browser_open`, `browser_snapshot`, `browser_click`, `browser_fill`, `browser_eval` |
| Probar y revisar una UI | `browser_audit`, `browser_emulate`, `browser_screenshot` |
| Manejar cualquier app de escritorio | `desktop_launch`, `desktop_screenshot`, `desktop_click`, `desktop_type`, `desktop_key` |
| Correr subagentes en paralelo | `cursor_spawn`, `cursor_wait`, `cursor_control`, `cursor_message` |
| Coordinarse con agentes hermanos | `board_read`, `board_post` |
| Reportar progreso y resultados | `cursor_report`, `cursor_complete`, `cursor_fail` |
| Pedirle ayuda a un humano | `human_request`, `events_wait` |
| Administrar workspaces | `workspace_create`, `workspace_op`, `workspace_info` |
