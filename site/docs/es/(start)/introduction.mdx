Agora es un runtime de escritorio nativo para agentes, creado por [Olimpia](https://olimpia.dev). Un único daemon en Go le da a cada agente una computadora Linux real (Chromium, apps X11, una terminal) sin levantar un escritorio ni un navegador por agente. Los agentes son **cursores**: tienen identidad, permisos acotados, su propio puesto de entrada, sus propias pestañas, una jerarquía padre-hijo y resultados estructurados.

## Por qué [#why]

Los escritorios remotos se hicieron para una persona mirando una pantalla. Los agentes necesitan otra cosa:

- **Muchos agentes, una máquina.** Cinco agentes en un mismo workspace de Agora comparten un display Xvfb y un Chromium, con una ventana cada uno. Eso son unos 326 MB contra 1,45 GB de cinco stacks separados de Xvfb + noVNC + Chrome.
- **Entrada que no choca.** Cada cursor recibe su propio puntero y teclado MPX cuando lo necesita, y las acciones del navegador van directo a la pestaña por CDP. Dos agentes pueden escribir en dos ventanas al mismo tiempo.
- **Primero control semántico, píxeles cuando hace falta.** Un snapshot compacto con referencias a elementos (`[e3] button "Sign in"`) tarda alrededor de 1 ms y cuesta una fracción de los tokens de una captura de pantalla. El control por píxeles sigue estando para canvas, CAPTCHAs y cualquier app de escritorio.
- **Humanos en el circuito.** Cuando un agente se topa con un CAPTCHA o un login, pide un humano. Tomás el control desde el visor, lo resolvés y se lo devolvés; el agente sigue en la misma pestaña y sesión.
- **Nada corre si nadie mira.** Sin visores no hay captura ni codificación. Los workspaces quedan inactivos, se congelan o se suspenden a disco y vuelven con sus pestañas.

## Agora vs noVNC

Medido con `go run ./cmd/agora-bench` contra Xvfb + x11vnc + noVNC + Chrome en un Ryzen 5 3400G (8 hilos). Los resultados completos están en la página de [benchmarks](/benchmarks).

| | Agora | Stack noVNC |
| --- | ---: | ---: |
| Escritorio vacío, memoria | 36 MB | 82 MB |
| Escritorio vacío, arranque | 98 ms | 246 ms |
| Cinco agentes con navegador, memoria | 326 MB | 1454 MB |
| Agente nuevo listo | 156 ms | 521 ms |
| Clic hasta `mousedown` en el DOM (p50) | 1,1 ms | 3,9 ms |
| Ancho de banda de streaming, 1 visor | 303 kbit/s | 5862 kbit/s |
| Workspace suspendido, memoria | 41 MB | no es posible |
