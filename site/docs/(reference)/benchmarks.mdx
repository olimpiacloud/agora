## Runtime vs noVNC

`go run ./cmd/agora-bench` runs the same scenarios on Agora and on a baseline of Xvfb + openbox + x11vnc + websockify (noVNC) + Google Chrome. Memory is PSS summed over every process of each stack, Chromium included. CPU is sampled over 10 s windows.

### Reading the numbers

- **Where Agora wins big:** many agents (one desktop and one Chromium instead of a stack each), input latency through its own MPX seats, streaming bandwidth (H.264 instead of raw RFB) and suspended workspaces, which noVNC cannot do without losing the session.
- **Where it costs more:** a streaming viewer uses more server CPU than raw RFB, because Agora encodes H.264. Frame rate adapts to keep this down (8 fps observing, 15 fps watching, 30 fps while interacting), and with no viewers nothing is encoded at all.
- **Cold start and resume** are slower than one fresh noVNC stack because Agora restores the previous tabs for their owners instead of starting empty.

## Subagent tokens

Three reproducible tasks (`bench/agent_bench.py`: a purchase in a local store, a search on olimpia.dev and a visual review), two runs each, Claude Sonnet 5.5 subagents launched by Agora. Cost is computed from the Claude Code transcripts at API prices, deduplicated by message id.

| Configuration | Correct | Cost (6 tasks) | Turns | Cache reads | Total time |
| --- | ---: | ---: | ---: | ---: | ---: |
| Before | 6/6 | $2.009 | 40 | 2.47 M | 175 s |
| Round 1 | 6/6 | $0.308 | 29 | 0.27 M | 69 s |
| Round 2 | 6/6 | $0.246 | 31 | 0.25 M | 60 s |
| Round 2, effort low | 6/6 | $0.227 | 29 | 0.24 M | 54 s |

Initial context per subagent went from 66,700 to 7,500 tokens. A real UI audit of the olimpia.dev landing page with the same prompt went from $0.927 to $0.299 and from 21 to 17 turns, with the same number of screenshots.

What changed: the lean Claude Code launcher, tool profiles by permission with one-line descriptions, incremental observations after every action, 1024 px JPEG screenshots by default, and real per-cursor usage reporting. Details in [token efficiency](/agents/tools#token-efficiency).

## Run it yourself

```bash
go build -o bin/agora ./cmd/agora
go run ./cmd/agora-bench
```

Results are written to `bench/results/`.
