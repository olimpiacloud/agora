## Keep your data

This stops the service and removes the binary and the systemd unit, but keeps `/var/lib/agora` (workspaces, browser profiles with their logins, checkpoints and tokens). Reinstalling picks everything up again.

```bash
curl -fsSL https://agora.olimpia.dev/uninstall.sh | sh
```

## Remove everything

Add `--purge` to also delete the state directory and the `agora` system user with its home (`/var/lib/agora-apps`):

```bash
curl -fsSL https://agora.olimpia.dev/uninstall.sh | sh -s -- --purge
```

:::danger
Purging deletes every workspace, browser profile (including logged-in sessions), checkpoint and token. It cannot be undone.
:::

## By hand

```bash
sudo systemctl disable --now agora
sudo rm -f /etc/systemd/system/agora.service /usr/local/bin/agora
sudo systemctl daemon-reload
```

And to purge:

```bash
sudo rm -rf /var/lib/agora
sudo userdel -r agora
```

If you ran `agora serve` as a normal user, its state lives in `~/.agora`.
