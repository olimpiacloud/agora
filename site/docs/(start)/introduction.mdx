Agora is an agent-native desktop runtime, built by [Olimpia](https://olimpia.dev). A single Go daemon gives every agent a real Linux computer (Chromium, X11 apps, a terminal) without starting a desktop or a browser per agent. Agents are **cursors**: they have an identity, scoped permissions, their own input seat, their own tabs, a parent-child hierarchy and structured results.

## Why

Remote desktops were built for one person looking at one screen. Agents need something else:

- **Many agents, one machine.** Five agents in one Agora workspace share one Xvfb display and one Chromium, with a window each. That is about 326 MB against 1.45 GB for five separate Xvfb + noVNC + Chrome stacks.
- **Input that does not collide.** Each cursor gets its own MPX pointer and keyboard on demand, and browser actions go straight to the tab over CDP. Two agents can type into two windows at the same time.
- **Semantic control first, pixels when needed.** A compact snapshot with element refs (`[e3] button "Sign in"`) takes about 1 ms and costs a fraction of the tokens of a screenshot. Pixel control is still there for canvases, CAPTCHAs and any desktop app.
- **Humans in the loop.** When an agent hits a CAPTCHA or a login, it asks for a human. You take control from the viewer, solve it and hand it back; the agent continues in the same tab and session.
- **Nothing runs when nobody watches.** With no viewers there is no capture and no encoding. Workspaces go idle, freeze or suspend to disk and resume with their tabs.

## Agora vs noVNC

Measured with `go run ./cmd/agora-bench` against Xvfb + x11vnc + noVNC + Chrome on a Ryzen 5 3400G (8 threads). Full results on the [benchmarks](/benchmarks) page.

| | Agora | noVNC stack |
| --- | ---: | ---: |
| Empty desktop, memory | 36 MB | 82 MB |
| Empty desktop, start | 98 ms | 246 ms |
| Five agents with a browser, memory | 326 MB | 1,454 MB |
| New agent ready | 156 ms | 521 ms |
| Click to DOM `mousedown` (p50) | 1.1 ms | 3.9 ms |
| Streaming bandwidth, 1 viewer | 303 kbit/s | 5,862 kbit/s |
| Suspended workspace, memory | 41 MB | not possible |
